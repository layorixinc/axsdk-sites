extension working page

This tab was opened by the AXSDK browser extension to run one installed Agent Pack task. The page itself is empty on purpose: it carries no script, loads nothing from anywhere, and does nothing on its own.

Every instruction that runs here is delivered by the extension through the browser's User Scripts API, from a Pack release you explicitly installed and approved, verified byte-for-byte against its published content digests before execution.

The extension closes this tab when the Pack is disabled or removed. 이 탭은 AXSDK 확장이 설치된 Agent Pack 작업을 실행하기 위해 연 페이지입니다. 페이지 자체는 아무 코드도 싣지 않습니다.
